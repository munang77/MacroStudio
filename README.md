# MacroStudio v2.4

윈도우용 마우스/키보드 매크로 프로그램. 파이썬 + tkinter + pynput + Pillow.

## 설치해서 쓰기 (파이썬 필요 없음)

`배포` 폴더의 **설치.bat** 을 실행하면 끝입니다. 관리자 권한도 필요 없습니다.

- `%LOCALAPPDATA%\Programs\MacroStudio` 에 설치
- 시작 메뉴 + 바탕화면 바로가기 생성
- 윈도우 **설정 > 앱** 목록에 등록 (거기서 제거 가능, 또는 `제거.bat`)
- 설정과 저장한 매크로는 `%LOCALAPPDATA%\MacroStudio` 에 보관 → 재설치해도 유지

배포할 때는 `배포` 폴더를 통째로 압축해서 넘기면 됩니다. 받는 쪽은 설치.bat 만 누르면 됩니다.

### 직접 빌드

```
빌드.bat
```

아이콘 생성 → PyInstaller 로 단일 exe 묶기 → `배포` 폴더 구성까지 한 번에 합니다
(PyInstaller 필요: `python -m pip install pyinstaller`).

## 자동 업데이트

설정 페이지 맨 위에서 현재 버전과 업데이트 상태를 볼 수 있습니다.

- **시작할 때 확인** 토글 (기본 켬) — 실행 2.5초 뒤 조용히 확인하고, 새 버전이 있을 때만 알립니다
- **업데이트 확인** 버튼 — 즉시 확인
- 새 버전이 있으면 버튼이 `v2.5 설치` 처럼 바뀌고, 누르면 받아서 교체 후 자동으로 다시 열립니다
- 받은 파일은 크기와 실행 파일 형식(MZ 헤더)을 확인한 뒤에만 적용합니다
- 설치본(exe)에서만 자동 설치가 되고, 소스 실행 중에는 알림만 뜹니다

업데이트는 GitHub 릴리스에서 받아옵니다. 확인할 저장소는 `config.json` 의 `update_repo`
값으로 바꿀 수 있습니다 (기본 `munang77/MacroStudio`). 릴리스에 `MacroStudio.exe` 를
첨부하고 태그를 `v2.5` 처럼 올리면 됩니다.

## 소스로 실행

```
실행.bat
```

또는

```
pythonw macro.py
```

처음 한 번만 패키지 설치가 필요합니다 (실행.bat 이 자동으로 확인·설치합니다).

```
python -m pip install -r requirements.txt
```

## 기능

### 기록 / 재생
- 마우스 이동, 클릭(좌·우·휠·옆 버튼), 휠 스크롤, 키보드 입력을 시간 간격까지 그대로 기록
- "마우스 이동 경로까지 기록" 을 끄면 클릭 지점만 기록해서 파일이 가볍고 재생이 정확함
- 반복 횟수(0 = 무한), 재생 속도 0.25 ~ 4배, 반복 사이 대기시간
- **부드럽게 이동** — 커서가 순간이동하지 않고 사람이 옮긴 것처럼 미끄러져 갑니다.
  기록된 시각은 그대로 지키면서 이동에만 시간을 씁니다 (끄면 예전처럼 즉시 이동)
- **시작 전 대기(초)** — 재생 버튼을 누른 뒤 대상 창으로 전환할 시간을 줍니다
- MacroStudio 창을 **직접** 누른 클릭만 기록에서 빠집니다 (재생 때 자기 버튼을 누르는 사고 방지).
  매크로 창이 뒤에 깔려 있고 그 위에 대상 프로그램이 떠 있으면 그 클릭은 정상적으로 기록됩니다
- 기록을 멈추면 로그에 종류별 개수(이동/클릭/휠/키)가 찍혀서 무엇이 안 잡혔는지 바로 보입니다
- 재생 중 진행률 표시, macros 폴더에 JSON 으로 저장/불러오기

### 기록이 안 될 때
- 설정 페이지에서 **실행 권한**을 확인하세요. 관리자 권한으로 도는 프로그램(일부 게임,
  설치 프로그램 등)은 일반 권한에서 입력이 기록되지도 재생되지도 않습니다.
  같은 페이지의 "관리자 권한으로 다시 실행" 버튼으로 바로 전환할 수 있습니다.
- 기록을 멈췄을 때 이벤트가 0개면 로그에 원인 안내가 뜹니다.
- FPS 게임처럼 마우스 원시 입력(raw input)을 쓰는 화면은 좌표를 옮기는 방식이 통하지 않을 수
  있습니다. 이 경우 키 입력·클릭은 되지만 시점 이동은 재현되지 않습니다.

### 자동 클릭
- 간격(ms), 버튼(좌/우/중), 단일/더블, 반복 횟수
- 현재 마우스 위치 또는 고정 좌표 (3초 뒤 좌표 캡처 버튼)
- 실행 횟수 실시간 표시

### 키 연타
- **키 시퀀스** — 키를 최대 6개까지 등록해 위에서부터 순서대로 반복 (예: Q → W → E → Ctrl+R)
  - 키마다 다음 키까지의 간격(ms)과 누르고 있는 시간(ms)을 따로 지정
  - 키가 하나면 예전처럼 단일 키 연타로 동작
- **실행 방식 2가지**
  - 단축키로 켜고 끄기 — 한 번 누르면 시작, 다시 누르면 정지
  - 누르고 있는 동안만 — 트리거를 쥐고 있는 동안 반복, 떼면 즉시 정지
    (트리거는 설정의 '키 연타' 단축키. 마우스 옆 버튼도 가능)
- 반복 바퀴 수 지정(0 = 무한), 실행 중 입력 횟수와 바퀴 수 표시
- 캡처 버튼으로 원하는 키를 직접 눌러 지정, 조합키는 `ctrl+c` 처럼 입력

### 화면 · 동작 설정

설정 페이지에서 취향대로 맞출 수 있습니다.

| 설정 | 내용 |
|---|---|
| 창 크기 | 보통 / 크게 / 최대화 (즉시 적용) |
| 창 크기·위치 기억 | 껐다 켜도 마지막 위치 그대로 (글자를 키웠으면 그만큼 넓혀서 복원) |
| 항상 위에 표시 | 다른 창 위에 고정 (즉시 적용) |
| 글자 크기 | 보통 / 크게 / 아주 크게 — 창과 사이드바도 같이 넓어집니다 (다시 켜면 적용) |
| 강조 색 | 파랑 · 초록 · 보라 · 주황 (다시 켜면 적용) |
| 시작·정지할 때 알림음 | 기록 시작/정지, 재생 완료에 짧은 소리 |
| 윈도우 켤 때 자동 실행 | 시작 프로그램 등록 (현재 사용자만, 관리자 권한 불필요) |
| 데이터 폴더 열기 | 설정과 저장한 매크로가 있는 폴더 |
| 설정 초기화 | 기본값으로 (저장한 매크로는 유지, 자동 실행 등록도 해제) |

### 전역 단축키 (기본값)

| 키 | 동작 |
|---|---|
| F6 | 기록 시작 / 중지 |
| F7 | 재생 시작 / 중지 |
| F8 | 자동 클릭 켜기 / 끄기 |
| F9 | 키 연타 켜기 / 끄기 |
| ESC | 전체 정지 |

다른 창이 떠 있어도 동작합니다. 설정 페이지에서 칸을 누르고 **원하는 키나 마우스 버튼을
그대로 누르면** 등록됩니다.

- 키보드 아무 키 (F1~F12, 문자, 숫자, Enter, Space 등)
- 마우스 오른쪽·휠·옆 버튼 4/5 (왼쪽 클릭은 화면 조작과 겹쳐서 제외)
- Ctrl / Shift / Alt / Win 조합키 (예: Ctrl + Q)
- 한/영 상태와 무관하게 자판 위치 기준으로 인식
- 오른쪽 × 로 해제, 6초 안에 입력이 없으면 자동 취소

보조키 없는 단축키는 기록에 포함되지 않습니다(조합키는 그대로 기록됩니다).

동작 규칙 몇 가지:

- Ctrl 등을 누르고 있어도 보조키 없는 단축키(ESC 등)는 그대로 먹습니다.
  단, `Ctrl + F7` 처럼 정확히 맞는 조합키가 등록되어 있으면 그쪽이 우선입니다.
- 자동 클릭 / 키 연타가 스스로 만든 입력에는 반응하지 않습니다 (자기 손으로 자기를 끄지 않도록).
- 재생 중에는 정지·재생 단축키만 동작합니다. 매크로가 되풀이하는 입력이 다른 기능을
  건드리지 않게 하기 위해서입니다.
- 앱의 입력칸에 커서가 있을 때는 한 글자짜리 단축키가 발동하지 않습니다.

## 파일 구조

```
macro-program/
  macro.py           앱 화면과 동작 연결
  core.py            기록기 / 재생기 / 반복 실행기 (UI 와 분리, 단독 테스트 가능)
  winput.py          윈도우 SendInput 입력 주입 (절대좌표 이동 + 스캔코드 키)
  updater.py         자동 업데이트 (릴리스 확인 / 내려받기 / exe 교체)
  ui_kit.py          Pillow 로 직접 그린 커스텀 위젯 (카드·버튼·토글·스테퍼·슬라이더·단축키칸)
  실행.bat           소스로 실행 (패키지 확인 포함)
  빌드.bat / build.py  exe 빌드 + 배포 폴더 구성
  make_icon.py       앱 아이콘(icon.ico) 생성
  install.ps1 / 설치.bat    설치 (바로가기 + 앱 목록 등록)
  uninstall.ps1 / 제거.bat  제거
  requirements.txt   의존성
  배포/              배포용 묶음 (exe + 설치 스크립트)
```

설치본은 설정·매크로를 `%LOCALAPPDATA%\MacroStudio` 에, 소스 실행은 소스 폴더에 저장합니다.

## 알아둘 점

- 재생은 기록 당시의 절대 좌표를 그대로 재현합니다. 해상도나 창 위치가 달라지면 결과도 달라집니다.
- 관리자 권한으로 실행 중인 프로그램을 제어하려면 이 프로그램도 관리자 권한으로 실행해야 합니다.
- 일부 게임은 안티치트가 가상 입력을 차단하거나, 약관으로 자동 입력을 금지합니다. 사용 전에 해당 서비스 규정을 확인하세요.
- 재생 중 ESC 를 누르면 눌린 상태로 남은 키와 마우스 버튼까지 모두 떼어냅니다.
- 두 번 실행해도 창은 하나만 뜹니다. 이미 떠 있으면 그 창을 앞으로 올립니다
  (두 개가 돌면 단축키가 두 번씩 먹고 재생 입력도 두 배로 나갑니다).
